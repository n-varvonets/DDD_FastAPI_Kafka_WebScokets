## 📚 Дополнительные пояснения по DDD

### 🧩 **Различие между Доменными и Прикладными сервисами**

Представь, что ты пришел в ресторан 🍽️:

- **Доменные сервисы** — это шеф-повара 👩‍🍳. Они точно знают, как приготовить каждое блюдо (бизнес-правила). Но они не обслуживают клиентов напрямую.
- **Прикладные сервисы** — это официанты 🧑‍💼. Они берут заказ от клиента, сообщают шеф-повару, что готовить, и затем подают блюдо.

#### 📌 Реальный пример:

- Клиент заказывает пиццу 🍕 (прикладной сервис принимает заказ).
- Официант идёт на кухню и говорит повару (прикладной сервис вызывает доменный сервис).
- Шеф-повар готовит пиццу (доменный сервис).
- Официант несёт пиццу клиенту (прикладной сервис доставляет результат).

#### 📌 Схема взаимодействия:
```
Клиент → Прикладной сервис (заказ) → Доменный сервис (готовка) → Прикладной сервис (подача) → Клиент
```

#### 📌 Простая реализация в коде:
```python
class PizzaCook:
    def cook(self, pizza_type):
        print(f"Готовлю {pizza_type} пиццу!")

class PizzaOrderingService:
    def __init__(self):
        self.chef = PizzaCook()

    def order_pizza(self, pizza_type):
        print("Заказ принят!")
        self.chef.cook(pizza_type)
        print("Пицца доставлена клиенту!")

service = PizzaOrderingService()
service.order_pizza("Маргарита")
```

### 📣 **Различие доменных событий и где они находятся**

Представь, ты выиграл в соревновании по бегу 🏃:

- Само событие («Ты победил!») — это доменное событие.
- Кто-то кричит: «Ты победил!» (генерирует событие).
- Судья записывает результат (доменный обработчик события).
- Родители поздравляют тебя и покупают подарок 🎁 (прикладной обработчик события).
- Газета пишет статью о твоей победе 📰 (инфраструктурный обработчик).

#### 📌 Схема событий:
```
Событие: «Ты победил!»
│
├─ Домен: Судья записывает результат
├─ Прикладной: Родители дарят подарок
└─ Инфраструктура: Газета пишет статью
```

### 📦 **Доменный сервис и событие в одном агрегате**

Агрегат — это семья 🏡:

- Родители — основной объект (корень агрегата).
- Дети, домашние питомцы — связанные объекты внутри агрегата.
- Доменный сервис — это правила, по которым семья живёт («воскресный ужин всегда вместе»).
- Событие — «Родился новый ребёнок».

#### 📌 Пример из жизни:
- В семье родился ребёнок → это событие.
- Вся семья собирается на семейный совет, чтобы решить важные вопросы (доменный сервис).

#### 📌 Реализация в коде:
```python
class Family:
    def __init__(self, parents):
        self.parents = parents
        self.children = []

    def add_child(self, child_name):
        self.children.append(child_name)
        print(f"Родился новый ребёнок: {child_name}!")
        self.family_meeting()

    def family_meeting(self):
        print("Семья собирается на совет.")

my_family = Family(parents=["Мама", "Папа"])
my_family.add_child("Ваня")
```

### ⚙️ **Почему доменная логика не привязана к одной сущности?**

Представь школьную игру в футбол ⚽:
- Один игрок не может самостоятельно играть всю игру, нужны правила и команда.
- Правила игры — это доменные сервисы, они не относятся к отдельному игроку.

**Доменная логика** — это правила, которые нужны для игры всей команде, а не отдельному игроку.

### 📗 **Дополнительное объяснение**

Представь библиотеку 📚:

- Доменный сервис: правила сортировки книг по жанрам и авторам.
- Прикладной сервис: библиотекарь помогает читателю найти нужную книгу, пользуясь правилами сортировки.
- Доменное событие: Поступила новая книга в библиотеку.
- Обработчики: библиотекарь ставит книгу на полку (домен), уведомляет читателей о новинке (прикладной), пишет об этом в местной газете (инфраструктура).
